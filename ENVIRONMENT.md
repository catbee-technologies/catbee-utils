
## Environment Variables

|             ENV              |  type   |          default        | required |
| ---------------------------- | ------- | ----------------------- | -------- | 
| LOGGER_NAME                  | string  | _function_              |          |
| LOGGER_LEVEL                 | string  | info                    |          |
| LOGGER_PRETTY                | boolean | false                   |          |
| LOGGER_COLORIZE              | boolean | false                   |          |
| LOGGER_SINGLE_LINE           | boolean | false                   |          |
| LOGGER_DIR                   | string  |                         |          |
| CACHE_DEFAULT_TTL            | number  | 3600000                 |          |
| SERVER_SKIP_HEALTHZ          | boolean | false                   |          |
| npm_package_name             | string  | @catbee/utils           |          |
